# Assignment 6 – Tomato Leaf Disease Classification using CNN

This assignment develops a **Convolutional Neural Network (CNN)** for classifying tomato leaf diseases from images.

### Work Covered
- Downloaded the tomato leaf disease dataset using KaggleHub.
- Loaded and preprocessed images using TensorFlow.
- Resized images to 128×128 and normalized pixel values.
- Built a CNN using convolution, max-pooling, dense, and dropout layers.
- Trained and evaluated the model.
- Generated accuracy/loss plots, confusion matrix, and classification report.
- Saved the trained model in `.keras` format.
- Tested the model on a user-uploaded leaf image and displayed the predicted disease with confidence.

### Tech Stack
**Python, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow/Keras, KaggleHub**

### Dataset
**Tomato Leaf Diseases Dataset** downloaded through KaggleHub.
