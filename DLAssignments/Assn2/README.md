# Assignment 2 – Wine Classification using ANN

This assignment builds a **multi-class Artificial Neural Network (ANN)** to classify wine samples into three different classes.

### Work Covered
- Loaded the Wine dataset from Scikit-learn.
- Performed data exploration and visualization.
- Standardized the input features.
- Built an ANN using Dense and Dropout layers.
- Applied L2 regularization and Early Stopping.
- Evaluated the model using accuracy, classification report, and confusion matrix.

### Tech Stack
**Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, TensorFlow/Keras**

### Dataset
Built-in **Wine dataset** provided by Scikit-learn.
