# Assignment 3 – ANN with Forward and Backpropagation

This assignment demonstrates the working of a neural network by implementing **forward propagation and backpropagation** using TensorFlow.

### Work Covered
- Loaded and preprocessed the Iris dataset.
- Standardized the input features.
- Built a multi-layer neural network for Iris classification.
- Implemented forward propagation.
- Used `GradientTape` to calculate gradients and perform backpropagation.
- Trained the network using the Adam optimizer.
- Visualized loss and accuracy during training.
- Evaluated the trained model on test data.

### Tech Stack
**Python, NumPy, Matplotlib, Scikit-learn, TensorFlow/Keras**

### Dataset
Built-in **Iris dataset** provided by Scikit-learn.
