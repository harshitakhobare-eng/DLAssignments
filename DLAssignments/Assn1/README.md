# Assignment 1 – Diabetes Prediction using ANN

This assignment implements a **feed-forward Artificial Neural Network (ANN)** using TensorFlow/Keras to predict diabetes outcomes.

### Work Covered
- Loaded and explored the Pima Indians Diabetes dataset.
- Handled missing values and performed data visualization.
- Standardized input features and split the data into training and testing sets.
- Built and trained an ANN with ReLU and Sigmoid activation functions.
- Evaluated the model using test accuracy and loss.
- Visualized training/validation accuracy and loss.

### Tech Stack
**Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, TensorFlow/Keras**

### Dataset
`diabetes.csv` – Pima Indians Diabetes dataset.
